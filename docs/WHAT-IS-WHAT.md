# Как устроен Cutrix

## C++: `src/main.cpp`

Это точка входа приложения. Создаётся `QGuiApplication`, задаются имя и версия программы, затем `QQmlApplicationEngine` загружает окно `Main.qml`.

Пока C++ почти не содержит логики монтажа — это нормально для первого шага. Позже в C++ будут модели проекта, клипов и дорожек, а также связь с видеодвижком.

## QML: `qml/Main.qml`

QML описывает, как выглядит интерфейс: панели, кнопки, цвета, списки и расположение элементов. Например, объект `palettes` содержит четыре цветовые схемы, а `currentTheme` хранит выбранную тему.

Сейчас интерфейс собран в одном файле, чтобы его было легче рассмотреть целиком. После проверки разделим его на отдельные компоненты: медиатеку, предпросмотр, таймлайн и панель свойств.

## CMake: `CMakeLists.txt`

CMake находит библиотеки Qt, собирает C++ и включает QML в модуль `Cutrix`. Ninja выполняет саму сборку по созданной конфигурации.

## Что является демонстрацией

- Карточки в медиатеке — примеры, а не файлы с диска.
- Город в центральном окне рисуется как графика QML Canvas, а не декодируется из видео.
- Клипы и дорожки внизу только показывают будущий вид таймлайна.
- Диалог выбора файла пока показывает путь в строке состояния, но не загружает медиа.

Это сделано намеренно: сначала проверяем каркас и стиль интерфейса, затем поэтапно добавляем реальные функции.
