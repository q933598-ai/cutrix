# Cutrix

Cutrix — пиксельный видеоредактор для Linux на C++20, Qt 6 и QML. Цель проекта — лёгкий локальный редактор с понятным интерфейсом и инструментами, которые покрывают повседневный монтаж.

**Активная разработка:** ветка `test/ui-prototype`. Возможны ошибки таймлайна, предпросмотра и экспорта; сборка не заменяет ручную проверку на реальных видео.

## Возможности текущего прототипа

- Project Hub: создание, открытие и список недавних проектов.
- Темы Tokyo Night, Everforest, Catppuccin и Rosé Pine; масштабируемый интерфейс.
- Импорт видео, аудио и изображений; медиатека с миниатюрами и поиском.
- Многодорожечный таймлайн с перемещением клипов, разрезанием, удалением, undo/redo и сохранением состояния проекта.
- Предпросмотр монтажа с трансформацией клипов: позиция, масштаб, поворот и прозрачность.
- Переходы на клипе: плавное появление и затухание с изменением длительности; переходы видны в предпросмотре и применяются при FFmpeg-экспорте.
- Единый пиксельный стиль ползунков по всему интерфейсу.
- Базовая цветокоррекция: яркость, контраст, насыщенность и пресеты.
- Инструменты аудио: 10-полосный EQ (31 Гц–16 кГц, ±12 dB) с пресетами «Ровный», «Басы», «Речь», «Высокие» и «Рок»; громкость, панорама, fade-in/fade-out, отключение звука, нормализация, компрессор, шумоподавление и лимитер.
- Настройки аудио сохраняются в проекте и применяются при FFmpeg-экспорте; громкость, mute и затухания учитываются в предпросмотре. EQ и обработка в реальном времени пока не подключены.
- Приближение/отдаление, анимированный zoom и реверс видео/звука.
- Два варианта размытия: параметр самого клипа и отдельный FX-клип на таймлайне; предпросмотр и FFmpeg-экспорт.
- Экспорт через FFmpeg с выбором разрешения и FPS, включая аппаратное кодирование, если доступно.
- Автосубтитры через локальный `whisper-cli` и выбранную модель Whisper.

## Зависимости на CachyOS / Arch Linux

```bash
sudo pacman -S --needed base-devel cmake ninja qt6-base qt6-declarative qt6-multimedia ffmpeg
```

Для автосубтитров дополнительно нужен `whisper-cli` и модель Whisper в поддерживаемом формате.

## Сборка и запуск

```bash
git switch test/ui-prototype
git pull --ff-only origin test/ui-prototype
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel 2
./build/cutrix
```

Требуется Qt 6.5 или новее.

## Сборка пакетов

- Arch/CachyOS: см. [packaging/arch/PKGBUILD](packaging/arch/PKGBUILD). `makepkg` создаёт файл `.pkg.tar.zst`, который устанавливается через `pacman -U`.
- Локальный Flatpak: см. [инструкции](packaging/README.md) и манифест в `packaging/flatpak/`.
- Текущий roadmap: [docs/ROADMAP.md](docs/ROADMAP.md).

Пакетные рецепты пока предназначены для разработки. Перед публичным распространением нужно выбрать и добавить лицензию проекта, затем проверить сборку и установку на чистом окружении.

## Структура

- `src/main.cpp` — точка входа и создание QML-приложения.
- `src/ProjectStore.*` — данные проектов и пользовательские настройки.
- `src/MediaTools.*` — анализ медиа, миниатюры, реверс и распознавание речи.
- `src/ExportController.*` — построение FFmpeg-фильтров и экспорт.
- `qml/Main.qml` — интерфейс проекта, таймлайна, эффектов и предпросмотра.
- `packaging/` — desktop-файл, иконка и рецепты пакетов.
