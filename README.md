# Cutrix

Пиксельный видеоредактор для Linux на C++ и Qt/QML.

> **Текущий статус:** UI-прототип в ветке `test/ui-prototype`. Это ещё не полноценный монтажный редактор: демонстрационные клипы на таймлайне и графика в предпросмотре не являются реальным видео.

## Что есть в прототипе

- оболочка приложения на C++20, Qt 6 и QML;
- тёмный пиксельный интерфейс;
- темы Tokyo Night, Everforest, Catppuccin и Rosé Pine;
- макеты медиатеки, предпросмотра, свойств, экспорта и многодорожечного таймлайна;
- импорт нескольких реальных файлов через системный диалог выбора;
- список импортированных файлов в медиатеке (пока без декодирования и миниатюр).

## Что пока не реализовано

- определение метаданных (длительность, разрешение, размер) и генерация миниатюр;
- настоящее декодирование и воспроизведение видео/аудио;
- рабочий таймлайн с перемещением и обрезкой клипов;
- сохранение проекта, эффекты и экспорт;
- применение настроек цветокоррекции к реальному изображению.

## Зависимости на CachyOS / Arch Linux

```bash
sudo pacman -S --needed base-devel cmake ninja qt6-base qt6-declarative qt6-quickcontrols qt6-multimedia
```

## Сборка и запуск

Из корня репозитория:

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/cutrix
```

Требуется Qt 6.5 или новее.

## Структура

- `src/main.cpp` — точка входа C++, создаёт приложение Qt и загружает QML.
- `qml/Main.qml` — текущий интерфейс-прототип.
- `CMakeLists.txt` — конфигурация сборки и QML-модуля.
- `docs/WHAT-IS-WHAT.md` — пояснение архитектуры для начинающих.
