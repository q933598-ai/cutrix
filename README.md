# Cutrix

Пиксельный видеоредактор для Linux на C++20 и Qt/QML.

> **Текущий статус:** UI-прототип в ветке `test/ui-prototype`. Project Hub, создание и открытие файлов проектов и сохранение настроек реализованы как первый рабочий слой; полноценный монтажный движок пока в разработке.

## Что есть в прототипе

- пиксельный интерфейс с квадратными рамками и моноширинным шрифтом;
- темы Tokyo Night, Everforest, Catppuccin и Rosé Pine;
- сохранение выбранной темы и масштаба текста между запусками;
- Project Hub с карточками недавних проектов, поиском и сортировкой по названию или дате открытия;
- создание проекта `.cutrix` с названием, разрешением и FPS;
- открытие существующих файлов `.cutrix` и сохранение списка недавних проектов;
- макеты медиатеки, предпросмотра, свойств, экспорта и многодорожечного таймлайна;
- импорт нескольких файлов через системный диалог выбора.

## Ограничения

- файл `.cutrix` пока сохраняет метаданные проекта, но не состояние таймлайна, эффекты или импортированные медиа;
- карточки используют условную пиксельную миниатюру, автоматическая генерация миниатюр ещё не подключена;
- таймлайн и свойства остаются демонстрационными;
- реальное декодирование, полноценный монтаж и экспорт видео ещё не реализованы.

## Зависимости на CachyOS / Arch Linux

```bash
sudo pacman -S --needed base-devel cmake ninja qt6-base qt6-declarative qt6-multimedia
```

## Сборка и запуск

Из корня репозитория:

```bash
git switch test/ui-prototype
git pull
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/cutrix
```

Требуется Qt 6.5 или новее.

## Где хранятся настройки

Cutrix использует `QSettings` для хранения темы, масштаба интерфейса и списка недавних проектов в пользовательском каталоге конфигурации приложения. Проекты сохраняются отдельно в выбранные пользователем файлы `.cutrix`.

## Структура

- `src/main.cpp` — точка входа и подключение хранилища к QML.
- `src/ProjectStore.h`, `src/ProjectStore.cpp` — файлы проектов и сохранённые настройки.
- `qml/Main.qml` — Project Hub и текущий интерфейс редактора.
- `CMakeLists.txt` — конфигурация сборки.
